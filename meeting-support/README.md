# Meeting Support — 会議サポートツール

会議中の発話を自動で文字起こしし、内容に連動してスライドを自動生成・自動表示する単一HTMLのWebアプリ。

## できること

| モード | 内容 |
|---|---|
| **A: 自動スライド生成** | 文字起こしからキーセンテンス・キーワードを抽出し、設定間隔(5〜12秒)で見栄えの良いテキストスライドを自動生成・切替。OpenAIキー設定時は「🎨 画像生成」でAI画像スライドも挿入可能 |
| **B: 資料の自動提示** | 画像・PDFをフォルダごと読み込み、事前にタグ付け(自動+手動+AI)。会話中に関連ワードが出たら該当資料を自動表示 |
| **A+B ハイブリッド(既定)** | 資料マッチを優先し、マッチがなければテキストスライドを生成 |

## 使い方

### 1. 起動

**Web版(推奨)**: main へのマージ後、https://ux-lab.jp/meeting-support/ を Chrome で開くだけで使えます(GitHub Pages で配信。反映まで1〜2分)。

ローカルで使う場合、マイク(音声認識)は **HTTPS または localhost** でのみ動作します。`index.html` をダブルクリック(file://)で開くとマイクは使えません(デモ入力は可)。

```bash
# このフォルダで
python3 -m http.server 8000
# → http://localhost:8000 を Chrome で開く
```

原本はこの `meeting-support/index.html` です。公開版は `docs/meeting-support/index.html` に同一内容を配置しており、原本を更新したら同じ場所にコピーしてください。

### 2. 文字起こし

- **ブラウザ内蔵(既定)**: 無料・APIキー不要。Chrome 推奨。
- **Whisper API**: 高精度。設定で OpenAI APIキーを入力し、エンジンを切替。約5秒ごとに音声チャンクを送信(従量課金)。

「🎤 文字起こし開始」でマイク許可 → 話すと下部ティッカーに文字が流れ、間隔ごとにスライドが切り替わります。

### 3. モードB(事前資料)

1. 「📁 資料」→「📂 フォルダ読込」で画像(png/jpg/webp/gif)・PDFを一括登録
2. PDFはページ単位に分解され、**ページ本文から自動でタグを抽出**(事前スクリーニング)
3. タグはカンマ区切りで手動編集可。「✨ AIタグ」でAIによる画像内容のタグ付けも可能(要APIキー)
4. 会話にタグと一致する語が出ると、その資料が自動表示されます(同じ資料の連続表示はクールダウンで抑制)
5. 資料クリックで即時表示、「📌 ピン」で自動切替を一時停止

タグはブラウザ(localStorage)に保存され、次回同じファイル名を読み込むと復元されます。

### 4. APIキー(すべて任意)

| キー | 使う機能 |
|---|---|
| OpenAI | Whisper文字起こし / AI画像生成(gpt-image-1、失敗時dall-e-3) / AIタグ付け(gpt-4o-mini) |
| Anthropic | 要点抽出の高精度化(Claude Haiku) / AIタグ付け(vision) |

キーは端末の localStorage にのみ保存され、各AI社のAPI以外に送信されません。共有PCでは使用後に消去してください。

### 5. 記録

設定モーダルから、文字起こし全文(.txt)/ 全ログ:文字起こし+スライド履歴+資料タグ(.json)をダウンロードできます。

## 動作確認(マイクなし)

下部の「デモ入力」欄に発話テキストを打ち込むと、マイクの代わりに文字起こしとして扱われます。「⏭ 今すぐ切替」で間隔を待たずにスライド更新できます。

## 技術メモ

- 単一HTMLファイル(CSS/JSインライン)。外部依存は pdf.js(CDN)と Google Fonts のみ
- 文字起こし: Web Speech API(自動再起動ラッパー付き)/ MediaRecorder + OpenAI Whisper
- キーワード抽出: カタカナ語・漢字連続語の頻度スコアリング(ストップワード除外)によるローカル処理
- サーバー・ビルドツール不要。データは一切外部保存されません(選択したAPIへの送信を除く)

## v1 スコープ外

動画生成(遅延・コスト面で非現実的)、話者分離
