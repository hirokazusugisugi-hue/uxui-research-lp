# Google Apps Script セットアップ手順

## 1. Google スプレッドシートを作成
1. https://sheets.google.com で新しいスプレッドシートを作成
2. シート名を「見学申込」に変更
3. A1〜F1 に以下のヘッダーを入力:
   - A1: タイムスタンプ
   - B1: お名前
   - C1: ふりがな
   - D1: メールアドレス
   - E1: 協会登録
   - F1: 参加方法

4. 同じスプレッドシートに「お問い合わせ」シートを追加（下のタブの＋ボタン）
5. A1〜E1 に以下のヘッダーを入力:
   - A1: タイムスタンプ
   - B1: お名前
   - C1: ふりがな
   - D1: メールアドレス
   - E1: お問い合わせ内容

## 2. Apps Script を設定
1. スプレッドシートのメニューから「拡張機能」→「Apps Script」を開く
2. 既存のコード（function myFunction...）を全て削除
3. `code.gs` の内容をすべて貼り付ける
4. ★ 3行目の `ADMIN_EMAIL` を自分のメールアドレスに変更する
5. ★ 会場情報・Zoom情報を実際の内容に変更する（20行目〜40行目付近）

## 3. ウェブアプリとしてデプロイ
1. 右上の「デプロイ」→「新しいデプロイ」をクリック
2. 歯車アイコンで「ウェブアプリ」を選択
3. 設定:
   - 説明: UX/UI研究会 フォーム受付
   - 次のユーザーとして実行: 自分
   - アクセスできるユーザー: **全員**
4. 「デプロイ」をクリック
5. 「アクセスを承認」→ Googleアカウントでログイン → 「許可」
6. 表示された **ウェブアプリのURL** をコピー

## 4. LP に反映
1. `docs/index.html` を開く
2. `const GAS_URL = ''` の部分に、コピーしたURLを貼り付ける
3. 保存してデプロイ

## 5. テスト
1. LP のフォームから見学申込を送信
2. 確認:
   - スプレッドシートにデータが記録されるか
   - 申込者にメールが届くか
   - 自分（管理者）にメールが届くか
