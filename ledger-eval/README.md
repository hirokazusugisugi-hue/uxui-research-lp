# Ledger Eval — 総勘定元帳から担当者別実績を集計・従業員評価するツール

総勘定元帳(Excel / PDF)から仕訳を自動で抜き出し、担当者(従業員)ごとの売上・原価・経費・利益貢献を集計して、評価レポート(Excel)を新規生成するPythonデスクトップツールです。**データはすべてお使いのPC内で処理され、外部に送信されません。**

## できること

- **元帳の自動読み取り**: 手作成のExcel元帳・会計ソフト出力のPDF元帳の両対応。列構成(日付/勘定科目/補助科目/部門/摘要/借方/貸方/金額)は見出しから自動判別。和暦(令和6年4月1日・R6.4.1)やカンマ・△負数の金額表記にも対応
- **担当者の自動紐づけ**: ①補助科目 → ②部門 → ③摘要欄の名前 の順で判定。名簿ファイルで別名(「田中」=「田中太郎」)も定義可能。名簿がなければ補助科目・部門から自動検出
- **評価レポート生成**(新規Excel、4シート):
  | シート | 内容 |
  |---|---|
  | サマリー | 担当者別の売上・原価・粗利・経費・利益貢献・件数・スコア・評価ランク(S〜D)+売上グラフ |
  | 月次推移 | 担当者×月の売上マトリクス+推移グラフ |
  | 明細(担当者別) | 紐づけ根拠となった全仕訳(検証用) |
  | 未割当 | 担当者に紐づかなかった損益系の仕訳(元帳・名簿の改善に使う) |

## セットアップ(初回のみ)

Python 3.9以上をインストール後:

```bash
pip install openpyxl pdfplumber
```

## 使い方

**GUI(かんたん)** — ダブルクリックまたは:

```bash
python app.py
```

①元帳ファイルを追加 → ②名簿(任意) → ④レポート生成、の順に押すだけです。

**CLI(コマンド)**:

```bash
python app.py 元帳1.xlsx 元帳2.pdf -o 評価レポート.xlsx --names 名簿.txt --year 2026
```

- `--names` 名簿ファイル(任意): 1行1名。`正式名,別名1,別名2` 形式で表記ゆれを吸収
- `--year` 元帳の日付が「4/1」のように年を含まない場合に補う年

**まず試す** — サンプル一式を同梱しています:

```bash
python app.py sample/サンプル元帳.xlsx sample/サンプル元帳.pdf --names sample/名簿サンプル.txt -o レポート.xlsx
```

## 評価スコアの考え方(カスタマイズ可)

```
スコア = 売上高 50% + 利益貢献 30% + 活動件数 20%(各項目は担当者内の最大値=100で正規化)
ランク: S(80〜) / A(60〜) / B(40〜) / C(20〜) / D
```

重み・ランク閾値・勘定科目の分類キーワードは `app.py` 冒頭の「設定」ブロックで自由に変更できます。

## 制限事項

- 画像スキャンのPDF(文字情報のないPDF)は読み取れません(OCRが必要)
- 勘定科目の売上/原価/経費の分類はキーワードベースの推定です。特殊な科目名は `app.py` の `REVENUE_KEYS` 等に追記してください
- 評価スコアは元帳から機械的に算出した「定量面の参考値」です。人事評価に使う際は定性評価と組み合わせてください
